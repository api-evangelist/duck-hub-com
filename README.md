Duckhub provides an AI‑powered QR menu platform for restaurants, enabling owners to create digital menus in minutes, integrate ChatGPT or Claude for automatic dish descriptions, translate into multiple languages, and sell with zero commission. The service offers a free forever plan and a range of paid features, positioning itself as a no‑fee, AI‑enhanced solution for modern eateries.

**Areas:** AI · QR · Restaurant · SaaS · Menu · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Duckhub: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
